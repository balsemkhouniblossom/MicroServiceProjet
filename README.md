# UtilisateurManagement

## Overview
`UtilisateurManagement` is a Spring Boot application designed for managing user registrations and logins. It allows users to create accounts, log in, and manage their profiles while integrating with a MySQL database for data persistence.

## Features
- User registration with email and password.
- User login with authentication.
- Email verification status.
- Integration with Twilio for SMS notifications.
- Email configuration for account management.

## Technologies Used
- Spring Boot
- Hibernate (JPA)
- MySQL
- Twilio API
- Java

## Prerequisites
- Java JDK 11 or higher
- MySQL Server
- XAMPP (for local server)
- Maven
